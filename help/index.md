# Help and Support

If you can’t find an answer here, try the [GitHub Discussions](https://github.com/rhizomatics/updates2mqtt/discussions) where you can find advice other people requested, or raise your own request.

If you think its a bug, raise a bug request, or see if anyone else has the same problem at the [GitHub Issues](https://github.com/rhizomatics/updates2mqtt/issues) page.

Have a look at the [What’s New](https://updates2mqtt.rhizomatics.org.uk/changelog/index.md) too, including any breaking changes.

## Community Guides

Walkthroughs written by people using Updates2MQTT, which can be a useful complement to these docs:

- [How To Keep HA Docker Setup Up-To-Date](https://www.diyenjoying.com/2026/01/30/how-to-keep-ha-docker-setup-up-to-date/) at DIY Enjoying - a full setup for Home Assistant running as a Docker container rather than HassOS, including the Mosquitto user, Docker networking, and a way of testing an update.
  - Written for v1.8. The `UPDATES2MQTT_*` env vars and the `updates2mqtt.compose_path` label in its examples aren’t used by Updates2MQTT, see the [FAQs](https://updates2mqtt.rhizomatics.org.uk/help/faqs/#containers), and `updates2mqtt.name` only works from v1.17.6.
