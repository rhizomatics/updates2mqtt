# Help and Support

If you can’t find an answer here, try the [GitHub Discussions](https://github.com/rhizomatics/updates2mqtt/discussions) where you can find advice other people requested, or raise your own request.

If you think its a bug, raise a bug request, or see if anyone else has the same problem at the [GitHub Issues](https://github.com/rhizomatics/updates2mqtt/issues) page.

Have a look at the [What’s New](https://updates2mqtt.rhizomatics.org.uk/changelog/index.md) too, including any breaking changes.
